# Telegram Bot & Crypto Backend Maintenance

**Independent backend engineering services by abbaas**

I work with teams that need help stabilizing, maintaining, and extending existing Telegram bots, Mini Apps, or crypto application backends.

My engineering background includes Rust (Axum, Tokio, SQLx), PostgreSQL, TypeScript/Next.js, Solana integrations, Docker, CI, and production-oriented reliability patterns. **Telegram/TON-specific requirements are scoped and verified per engagement**; this is a service offer, not a claim of prior client work on TON.

## Where I can help

- **Backend reliability:** API errors, timeouts, retries, structured logging, health checks, and incident analysis.
- **Bot and webhook integrations:** safe request handling, update deduplication, authentication boundaries, and operational troubleshooting.
- **PostgreSQL:** slow queries, migrations, transaction integrity, backup and recovery procedures.
- **Rewards and payments:** idempotency, claim/replay prevention, settlement state, and reconciliation controls.
- **Delivery operations:** Docker, CI/CD, deployment diagnostics, release checks, and rollback planning.
- **AI/API integrations:** provider timeouts, usage safeguards, streaming, and structured error handling.

I primarily work with Rust or TypeScript backends; other stacks are evaluated case by case.
